# Tsubasa

Tsubasa is a web browser for macOS. It is built on Chromium (by way of
[ungoogled-chromium](https://github.com/ungoogled-software/ungoogled-chromium)) with its own native
AppKit interface: pages sit side by side on a horizontal strip, grouped into spaces.

## Download

Get `Tsubasa.dmg` from the [latest release](https://github.com/aa-adibashraf/tsubasa/releases/latest),
open it and drag Tsubasa to Applications. It is signed with a Developer ID and notarized by Apple.

- Apple silicon Mac, macOS 14 or later
- No account needed

## Using it

- ⌘T opens the address and search field (a new install starts there)
- ⌘L shows the current page's address and controls
- Settings › Make Default sets Tsubasa as your default browser
